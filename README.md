# Тренажёр английской грамматики

Открыть: **https://sfrangulov.github.io/english-grammar/**

Показывает английское предложение с пропуском. Форму нужно **вписать** с клавиатуры — вариантов на выбор нет. Проверка мгновенная, с разбором правила по-русски.

Один самодостаточный HTML-файл: работает офлайн, ничего не устанавливается, никуда ничего не отправляет.

## Что тренирует

**Глаголы** — все двенадцать времён (Simple / Continuous / Perfect / Perfect Continuous × Present / Past / Future) в утверждении, отрицании и вопросе.

**Артикли** — 18 правил, которые собирают предложение из лексики, плюс 92 готовых предложения со своим разбором. Пул — около 600 предложений: в сессии на сто заданий по артиклям повторов около 11% вместо прежних 28%. Выбор между *a* и *an* идёт по звуку, а не по букве: *an hour*, но *a university*.

**Местоимения** — I / my / me по трём формам.

Всё идёт одним перемешанным потоком: угадать тип задания заранее нельзя.

## Как устроено

Задания не выбираются из списка, а собираются на лету: подлежащее × глагол × дополнение × маркер времени × время × форма. Внутри — правила спряжения (`-s`, `-ed`, `-ing`, три формы неправильных глаголов) и правила сочетаемости: глаголы состояния не попадают в Continuous, мгновенные тоже, Perfect Continuous берёт только длительные. Поэтому поток не кончается и не заучивается наизусть.

Время подсказывает только маркер внутри предложения — `yesterday`, `every day`, `right now`, `by that time`. Метка «Past Simple» появляется уже в разборе, до ответа её нет.

Полные и краткие формы равнозначны: `did not` = `didn't`, `is not` = `isn't` = `'s not`, `has gone` = `'s gone`. Если потерян только апостроф, тренажёр так и скажет.

## Как идёт занятие

Раунд из 20 заданий (можно 10, 40 или без конца). Полоса под шапкой показывает всю сессию: зелёный блок — верно с первой попытки, красный — нет, текущий подсвечен цветом темы. В конце раунда — итог с разбивкой по временам и темам, где худшее сверху.

Ошибся — правильная форма не показывается сразу: даётся ещё две попытки, и обе с подсказкой. Сначала подсвечивается маркер времени в предложении. Потом тренажёр разбирает то, что ты написал, и называет это маркерами: «так пишут с *tomorrow* или *next week*, а здесь маркер — *yesterday*». Метка времени до конца попыток не появляется. Ответ раскрывается после третьей неудачи или по кнопке «Не знаю».

Задание, закрытое не с первой попытки, через несколько шагов возвращается и не уходит из очереди, пока не будет отвечено верно.

Ответил верно сразу — следующее задание появляется само, без лишнего нажатия.

## Управление

`Enter` — проверить, затем перейти к следующему · `Tab` — следующий пропуск · `Ctrl + Enter` — показать ответ.

В настройках можно выключить любую тему, любое из двенадцати времён и любую из форм.

## Самопроверка

Открыть страницу с `#test` в адресе — движок прогонит проверки орфографии окончаний, форм глагола и корректности сгенерированных заданий, результат покажет в консоли.
